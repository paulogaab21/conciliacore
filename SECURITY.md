# Security policy

This project is a technical demonstration and must not receive real financial data without an additional security, operations, and compliance review.

If you discover a vulnerability, do not open a public issue with exploitable details. Submit a private report through **GitHub Security Advisories** and include:

- the affected component and version;
- the observed impact;
- minimal reproduction steps;
- a suggested fix or mitigation, when available.

The threat model, implemented controls, and known boundaries are documented in [docs/security.md](docs/security.md).
